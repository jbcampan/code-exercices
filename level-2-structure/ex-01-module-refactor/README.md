# Ex-2.1 — Refactor a Script into an Importable Module

**Level:** 2  
**Estimated time:** 1h  
**Track:** Python → module-design

---

## Goal

Refactor a working Level 1 log-parser script into a clean, importable module. The real-world motivation: in a professional codebase, a script that "runs" is not enough — it must be importable, testable, and reusable by other files without triggering side effects.

---

## Concepts covered

- `if __name__ == "__main__"`: why it exists and what happens without it
- Difference between a **script** (meant to be executed) and a **module** (meant to be imported)
- `__all__`: explicitly declaring a module's public surface
- Separating business logic from the entry point
- Exporting structured data to CSV with the `csv` module

---

## Folder structure

```
ex-21/
├── data/
│   ├── access.log
│   └── errors.csv        # generated by main.py
├── log_parser.py         # module — zero print(), only functions
├── main.py               # entry point — orchestration only
└── report.py             # alternative consumer — proves reusability
```

---

## Instructions

**Input format** (`data/access.log`): space-separated log lines.

```
YYYY-MM-DD HH:MM:SS LEVEL service-name message text here
```

**What the scripts must do:**

1. `log_parser.py` — expose pure functions via `__all__`; no executable code at module level.
2. `main.py` — open the log, parse lines, filter errors, print a formatted report, export errors to CSV.
3. `report.py` — import `log_parser` and produce a *different* aggregation (e.g. errors by hour) to prove the module is reusable without copy-pasting logic.

---

## Functions to implement

```python
def parse_line(line: str) -> dict | None:
    """Parse a single log line into a dict with keys: date, time, level,
    service, message. Return None if the line is malformed."""

def filter_errors(entries: list) -> list:
    """Return only entries whose level is ERROR."""

def count_by_service(entries: list) -> list[tuple[str, int]]:
    """Return (service, count) tuples sorted by count descending."""

def format_entries(entries: list) -> list[str]:
    """Return a list of human-readable strings for the given entries."""

def to_csv(entries: list, path: str) -> None:
    """Export a list of log entry dicts to a CSV file at the given path."""
```

---

## Constraints

- `log_parser.py` contains **no `print()` calls** — only functions that return values.
- `main.py` contains **no parsing logic** — only function calls and `print()`.
- Both files sit in the same folder; no `sys.path` manipulation required.
- All file paths defined as **module-level constants**, never hardcoded inside functions.
- No executable code at module level (no bare calls outside `if __name__ == "__main__"`).

## Key takeaways

1. **`if __name__ == "__main__"` is a guard, not a style choice.** Without it, any `import log_parser` would execute your script's side effects — file I/O, prints, and all.
2. **A module's job is to return data, not to display it.** Keeping `print()` out of `log_parser.py` is what makes it usable by `main.py`, `report.py`, or a future test file without any changes.
3. **`__all__` is your module's public contract.** It tells other developers (and tools) exactly what your module exposes — everything else is an implementation detail.
